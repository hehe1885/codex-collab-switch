# Codex Collab Switch v1.0

单 Skill 发布版。附件 `codex-collab-switch-skill-v1.0.zip` 只包含一个 `codex-collab-switch` 文件夹，可直接放入 Codex 个人 Skill 目录。

## 安装

1. 下载本页的 `codex-collab-switch-skill-v1.0.zip`（不要误选 GitHub 自动提供的完整源码包）。
2. 解压，将整个文件夹放入 `~/.agents/skills/`；Windows 对应 `%USERPROFILE%\.agents\skills\`。
3. 确认目录为 `~/.agents/skills/codex-collab-switch/SKILL.md`，避免双层同名文件夹。已有版本请先备份。
4. 重启 Codex，在 Skill 选择器中选择 `codex-collab-switch`，输入“开启协同”或“退出协同”。CLI / IDE 也可以使用 `$codex-collab-switch 开启协同`。

## 功能

- 默认当前主模型独立执行，显式开启后仅当前对话协同。
- 同一个 Skill 负责开启与退出。
- 按运行环境能力选择执行模型和思考强度，支持唯一简称和纠错确认。
- 不写死模型版本，不写入项目 AGENTS.md，可按用户要求保存执行偏好。
- 修正文档中混用 `$`、`@` 和不同产品调用方式的表述，明确面向 Codex。

## 限制

Skill 为指令型工作流，需要 Codex 运行环境支持显式模型/强度委派；无法发现可用型号时需完整指定。实际客户端交互仍需实测，分叉历史与停止代理能力受运行环境限制。仓库提供 Windows/macOS/Ubuntu 安装与包结构 CI，具体结果见 Actions。
