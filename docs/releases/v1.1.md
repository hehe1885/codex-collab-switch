# Codex Collab Switch v1.1

本版本调整协同执行和审查流程，减少重复交接、重复检查与反复返工。

- 主模型按交付目标默认集中审查一次，必要时对修正结果进行一次定点复查。未解决的验收项、实质风险或用户要求的验证可以触发针对性补查。
- 已定位的小改动和交接会重复大量探索的任务可由主模型直接完成。适合独立交接的实现由所选执行代理完成。
- 执行代理运行相关检查并简要交付结果。相同失败再次出现时，根据证据定点诊断或尝试不同修法。
- 调整等待和日志回报方式，降低不必要的状态查询与上下文开销。

这些规则尚未经过用量对照测试，实际额度消耗取决于任务、模型和运行环境。

## 安装

下载附件 `codex-collab-switch-skill-v1.1.zip`，解压后将整个 `codex-collab-switch` 文件夹放入 `~/.agents/skills/`。Windows 对应 `%USERPROFILE%\.agents\skills\`。替换已有版本前请先备份，然后重启 Codex。

附件只包含 Skill 和许可证。完整源码、安装脚本和升级说明见仓库 README。
